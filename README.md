Gestur AI - Smart Hand Gesture Recognition
Sebuah asisten kecerdasan buatan berbasis *Computer Vision* yang dirancang untuk meningkatkan efisiensi dan interaksi pengguna melalui pengenalan gestur tangan. 
Proyek ini dibuat untuk membuktikan bahwa AI dapat digunakan sebagai alat bantu yang produktif untuk mempercepat tugas

Fitur Utama
-Real-time Hand Tracking: Mendeteksi dan melacak pergerakan serta *landmark* tangan menggunakan model MediaPipe 
-Audio Feedback / Voice Commands: Merespons gestur tertentu dengan *output* suara (file audio disimpan dan diproses secara efisien melalui audio_cache

Persyaratan Sistem 
Pastikan Python sudah terinstal di sistem Anda. Pustaka utama yang digunakan dalam proyek ini meliputi:
OpenCV
MediaPipe
pip install opencv-python mediapipe gtts pygame
pip install gTTS
